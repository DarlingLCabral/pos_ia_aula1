# Exemplo 00: Fundamentos de IA e Redes Neurais com TensorFlow.js

Exemplo prático do módulo de **Fundamentos de IA e LLMs para Programadores** do curso de Engenharia de IA Aplicada.

Este projeto demonstra o funcionamento básico de uma rede neural densa (*Multilayer Perceptron*) utilizando **TensorFlow.js** (`@tensorflow/tfjs-node`) em Node.js para classificar perfis de usuários (`premium`, `medium`, `basic`) com base em características normalizadas (idade, cor e localização).

---

## Pré-requisitos

- **Node.js** (versão 18 ou superior recomendada)
- **npm**

---

## Como Instalar e Rodar

1. Instale as dependências do projeto:
   ```bash
   npm install
   ```
   *(Nota: O TensorFlow.js para Node requer compilação de binários nativos, certifique-se de ter as ferramentas de compilação essenciais do seu sistema operacional se necessário).*

2. Execute o script de treinamento e predição:
   ```bash
   npm start
   ```
